## 实际能帮用户做什么

| 用户当前情况 | 主要交付 |
| --- | --- |
| 只有宽泛选题 | 2—3 个可研究问题、研究路线、检索词/检索式和最少资料清单 |
| 有文献摘要或片段 | 论点与来源的对应、支持度、未核书目与全文待查清单 |
| 有论文草稿 | 可复制修订文本、必要的实质性修改说明与证据映射 |
| 只需语言润色 | 直接给润色文本，保留数字、术语、原意及结论强度 |
| 有审稿意见 | 逐条回复草案、实际已见改动、稿件定位与待办事项 |
| 需要计算但不能运行工具 | 有输入前提的分析方案或代码模板；结果明确未运行 |

指令分别处理定量、质性、理论和文本研究。来源读取范围、出版身份、主张支持度与材料争议分开记录，防止把用户摘录误称为外部核实的原文。可以忠实转述提供材料里的数字并标“未独立复算”；不补造 DOI、页码、实验或统计结果。

## 如何导入与试用

1. 在中台专家管理的新建/导入入口，选择 **“从资源包导入” → “导入 YCPS / 完整包”**，选择上方 `.ycps.zip` 原文件，不要重新套一层目录压缩。
2. 导入确认页核对 `academic-writing-mentor`、版本 `1.0.0`、类型 `EXPERT`；检查中文/英文文案、三个任务标签、三个示例提示词、表格、画布与三张图片。
3. 本包使用独立的新 code。若目标环境已存在同名 code，应先核对该条目的归属和版本，不直接覆盖未知内容。
4. 导入后按环境的版本流程完成试用。联网、文档读取、代码运行与文件生成使用宿主实际已授权的能力；包本身不会自动增添这些工具或账号权限。
5. 先试一项贴近实际需求的任务，再用下列用例检验可靠性。真实会话输出与包内离线审查记录分开保存。

建议先试这两项：

> 我只想研究大学生使用生成式AI，暂时没有资料。请给我三个可以继续研究的问题，说明需要收集什么材料，不要编造研究现状。

> 请只润色，不加表格、不改变数字和结论强度：“在120名参与者中，干预组评分均值从12.3增加到13.1，但组间差异没有达到统计显著（p=0.08），还不能断定干预有效。”
