# 资讯速递专家：按证据交付的模板

模板按任务裁剪；方括号必须由实际材料替换。只有检索成功并读到原文，才把状态写为“已核原文”。

## 范围与检索记录

- **读者与议题**：[地区、主题、语言、用途]。
- **纳入窗口**：[起点、截止、时区；“今日”转成明确日期]。
- **实际检索**：[检索式、网站、取阅时间、可访问范围、未覆盖区域]。
- **材料状态**：[实时读到原站 / 用户给的快照 / 搜索摘要 / 失效或付费不可读]。

## 每条候选资讯的来源卡

| 字段 | 必填内容 |
| --- | --- |
| 主张 | 一句可争议或可核实的事实，注明声明者 |
| 原始出处 | 指向具体页面/文档的 URL、标题、发布机构、可定位段落 |
| 四种时间 | 事件时间；初次发布；更正/更新；本次取阅，均注明时区或“未知” |
| 来源关系 | 原发、独立采编、引用公告、通讯社通稿、转载、同一稿的新版 |
| 核验状态 | 已核原文、仅快照、仅摘要、冲突、待核 |
| 版本注记 | 旧版写法、改动内容、更新时间、是否影响结论 |

同一事实的转载不叠加为“多家证实”。相互矛盾时先列两边原句、版本和时间，追直接证据后再形成简报句。

## 读者可读简报

**范围**：[按哪段公开时间窗口收录；取阅截止；何处未查]。

**标题**：[简洁、与已核事实一致]。

每条采用：“[谁]于[公告时间]宣布/发布[可核事实]；[事件时间]将[发生什么]。[为何与读者相关]。[具体原始来源链接；若有更正另链或同页版本]。”若时间或事实未核，用“据所给材料”并标待核，不能把推测写成已经发生。短引只用必要词语，不复制整段新闻。

**版本与冲突**：[哪些旧稿仍在传播；本次采用哪版及依据；哪些相反说法未解决]。

**检索边界**：[最后取阅时间、不能访问的页面、实时性限制]。回溯某截止时刻时，晚于该时刻的更正应单列“事后更正”，不能改写当时已公开的信息集合。

## 用户要求订阅或监控时

先区分本次简报与未来任务。只有实际可用的调度工具成功建立，才写“已设置”并给可核对的设置；否则交付来源清单、检索式和建议手动复查节点，明确没有自动推送或提醒。
