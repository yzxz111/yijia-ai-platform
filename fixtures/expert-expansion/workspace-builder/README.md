## 使用方式

1. 在中台专家管理选择“从资源包导入”→“导入 YCPS / 完整包”，选择本专家的 `.ycps.zip`。
2. 核对 code、版本、EXPERT 类型，以及中英文说明、示例和画布。已有同名对象时先核对身份与版本。
3. 按当前环境的版本流程试用。说清每天要处理的任务、现有数据和目标设备；如有项目请给目录。专家先做可用的最小工作流，再核验保存和恢复。

首次可以这样试用：

> 请做一个今日工作台，能新增、编辑、完成任务，刷新后仍能找回。
